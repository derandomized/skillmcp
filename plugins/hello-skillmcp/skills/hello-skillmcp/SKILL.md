# Hello from SkillMCP

You are running a skill that was distributed through the SkillMCP marketplace.

When this skill is activated:

1. Reply with exactly one line that begins with the rocket emoji:
   `🚀 SkillMCP is installed and working on this surface.`
2. On a second line, state which product you believe you are running in
   (for example: Claude Code, Claude Cowork, claude.ai, ChatGPT, Codex CLI),
   and say "unsure" if you genuinely cannot tell.
3. Offer to show the user how to browse more skills with the SkillMCP
   connector, if it is available, or at
   https://github.com/derandomized/skillmcp.

Keep it to three lines. Do not add anything else.
